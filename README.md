### Deskripsi Proyek
Proyek ini membahas analisis kinerja siklus termodinamika mesin kalor menggunakan Siklus Otto dengan bantuan metode numerik.

### Tujuan
- Membuat model hubungan tekanan dan volume (P-V).
- Menghitung kerja siklus secara numerik.
- Menghitung efisiensi termal.
- Membandingkan hasil numerik dengan efisiensi teoritis Siklus Otto.

### Metode Numerik
1. Regresi
2. Interpolasi
3. Integrasi numerik metode trapesium

### Struktur Folder
- `data/` : Data keadaan siklus.
- `src/` : Program Python untuk perhitungan.
- `hasil/` : Diagram P-V dan ringkasan hasil perhitungan.
